# OCR Denoising Model

Модель для исправления ошибок OCR на старославянских текстах.

## Архитектура

Transformer encoder с механизмом копирования для исправления символьных ошибок OCR.

### Особенности обучения

Модель обучается исправлять:
1. **Символьные ошибки OCR** - замена похожих символов
2. **Замена окончаний** - ошибки в окончаниях слов
3. **Лишняя пунктуация** - случайные запятые, точки
4. **Артефакты переносов строк**:
   - `-,` в конце слов → заменяет на пробелы
   - `,` в начале слов → заменяет на пробел
   - Повторы окончаний → заменяет на пробелы

**Важно**: Модель использует пробелы как "символы удаления". При инференсе множественные пробелы убираются автоматически.

## Запуск обучения

```bash
python run_training.py
```

## Gradio интерфейс

```bash
python gradio_app.py
```

Интерфейс включает:
- Настройка размера окна и пересечений
- Повторные итерации обработки
- Проверка слов по словарю
- Препроцессинг артефактов переносов
- Визуализация изменений (красным - что было, зелёным - что стало)
